# Club Registry — canonical football identity layer

**Version:** 1.0.0 · **Status:** production foundation · **Replay-safe:** yes
(the crawler regenerates byte-identical output from a fixed club list +
deterministic renderer).

The Club Registry is the single source of truth for football club
identity and visual assets across the entire Insight platform (Sport
Hub, Gateway, Azteca, Explorer, Atlas). It removes any runtime
dependency on third-party logo APIs — every crest is Insight-owned and
ships with the consumer.

## Files

- `club_registry.json` — the canonical, versioned registry (this dir).
- Mirrors (byte-identical, written by the crawler):
  - `insight-runtime-go/pkg/clubregistry/club_registry.json` (Go embed)
  - `insight-azteca-flutter/assets/clubs/club_registry.json` (bundled)
- Crests: `insight-azteca-flutter/assets/clubs/<club_id>.png` (bundled).

## Schema

```json
{
  "club_id": "manchester_city",      // stable slug — the canonical key
  "name": "Manchester City",
  "short_name": "MCI",
  "country": "EN",
  "competition": "premier_league",   // primary competition
  "competitions": ["premier_league"],// all competitions it appears in
  "logo_path": "/clubs/manchester_city.png",
  "aliases": ["Man City", "Manchester City FC", "Manchester City"]
}
```

## Canonical resolution

Any name / short code / alias resolves to one `club_id`, case- and
accent-insensitive, punctuation-stripped:

```
"Manchester City" | "Man City" | "Manchester City FC" | "MCI" → manchester_city
"Atlético Mineiro" | "Atlético-MG"                            → atletico_mineiro
```

Resolvers (identical normalization on both sides):
- Go: `insight-runtime-go/pkg/clubregistry` — `Default().Resolve(q)` /
  `.Lookup(q)` over the embedded JSON.
- Dart: `insight-azteca-flutter/lib/clubs/club_registry.dart` —
  `ClubRegistry.instance.load()` then `.resolve(q)` / `.lookup(q)`;
  `ClubBadge` resolves registry-first to a bundled crest (initials
  fallback if unknown — never a runtime network call).

## Coverage (V1 competitions)

Brasileirão Série A + B, Copa do Brasil (drawn from A+B), Premier League,
La Liga, Serie A, Bundesliga, Ligue 1 (UCL/UEL reuse these club ids),
and World Cup 2018/2022 national teams. 101 entries in v1.0.0.

## Regenerating (append-only)

Edit `scripts/club_logo_crawler/clubs.py` (the curated source list),
then:

```
python3 scripts/club_logo_crawler/crawl.py
```

This re-renders the Insight-owned crests and rewrites the registry to
all three locations. `club_id`s are stable (slug of name); never rename
an existing one — add aliases instead.

## Logo ownership

Crests are generated by `scripts/club_logo_crawler/crawl.py` as generic,
Insight-owned shield marks (short code on a two-tone badge) — NOT scraped
third-party trademarks. To swap in licensed artwork later, replace
`render_crest()` with an asset loader; the registry contract is
unchanged.

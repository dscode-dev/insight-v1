# AZTECA-SEARCH-UX-RESTORE — Smoke Visual (manual)

1. Abrir Explorar SEM query → layout aprovado presente.
2. Hero "Radar da rodada" visível → toque leva ao Radar.
3. Seção "Descobrir": Clubes / Agentes / Discussões / Sinais (navegação real).
4. Campo de busca integrado ao corpo (filled, radius lg, prefixo, hint "Buscar partidas, clubes, agentes…").
5. Digitar "fla" → debounce → transição para resultados (sem salto de layout; campo permanece no lugar).
6. Tabs = All + categorias habilitadas (capabilities). SEM Teams/Players. SEM "Tendências"/Trending.
7. Trocar tabs preserva a query.
8. Abrir um card de usuário → detalhe; voltar → query/tab/scroll preservados.
9. Limpar a query (X) → volta ao Discovery (hero + grid reaparecem).
10. "Buscas recentes" aparece como SEÇÃO no Discovery (não tela cheia); selecionar re-executa; "Limpar" limpa.
11. Partial: com uma categoria falhando, All mostra resultados + banner "incompletos" (nunca vazio).
12. Offline (modo avião) → estado offline + retry (query preservada).
13. Timeout → estado de tempo esgotado + retry.
14. Dark mode / Light mode → identidade preservada nos dois.
15. Texto ampliado → sem overflow; cards e campo legíveis.
16. Nenhum layout anterior perdido; nenhuma busca deixou de funcionar.
